使用说明与 GitHub Pages 部署

怎么用

  1. 在生词录入区输入英文单词，选好章节（可粘贴原句），点「查询并保存」。
  2. 即时结果区立刻给出中文释义、教材语境推荐译法，以及「相关术语 / 常见搭配 / 易混概念 / 教材语境」四项中文拓展。
  3. 再次遇到同一个词时（哪怕换了章节），只会把这次的章节、原句与时间补充进原词条，不会生成第二条。
  4. 在词库列表里搜索、筛选、排序或按重要程度分组；点词条进入详情区修改译法、手动调分、标记掌握程度。

重要程度怎么算

自动分 = 基础分 38 + 教材核心概念 28 + 出现次数 × 5（最多 12 次） + 掌握情况（未掌握 +12 / 模糊 +4 / 已掌握 −28），再加上你在详情区的「手动调整」。≥72 分为重点攻克，48–71 分为常复习，其余为已巩固。标记已掌握后分数会自动降下来。

发布到 github.io

  1. 在 GitHub 新建一个仓库，把本目录里的 index.html 与 assets/ 一起上传到仓库根目录（无需构建、无需后端）。
  2. 打开仓库 Settings → Pages，Build and deployment → Source 选择 Deploy from a branch，分支选 main，目录选 / (root)，保存。
  3. 等待几十秒后访问 https://你的用户名.github.io/仓库名/ 即可。若仓库名就是 你的用户名.github.io，则直接访问根地址。
  4. 页面是纯静态的，所有词库数据保存在访问者自己的浏览器里；建议定期用「导出备份」保存 JSON 文件。

关于释义来源

内置了覆盖全书 12 章的中文术语表（257 条，含 125 个核心概念、37 条精编拓展）与通用英汉小词典（191 词），命中时无需联网即可显示释义。若遇到词表之外的生词，会尝试联网获取通用中文翻译；网络不可用时仍会生成完整中文拓展，并提示你手动补写释义。自动结果都可以修改。
